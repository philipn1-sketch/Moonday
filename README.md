# Moonday

A calm, private period and cycle tracker for iPhone, built with Expo.

* `src/core/cycle.ts` works out her periods, averages, predictions, fertile window, phase and flags, with tests in `src/core/__tests__`.
* Everything she logs stays on her phone (`src/data/db.ts`).
* `npm test`, `npm run typecheck`, and `node scripts/design-screens.js` for screenshots of the web preview.

Predictions are estimates and are never a form of contraception.
